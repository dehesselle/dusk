# Dusk - dim your screens

Dusk is a little tool that can dim individual screens in your multi-monitor setup by overlaying them with translucent black borderless windows. The usecase is that you don't have to turn off monitors if you want to get rid of distractions/brightness, e.g. when watching a movie.  
This is not a tool to save energy or reduce brightness on hardware-level.

![Alt text](/doc/dusk_main_window.png "main window")

## Usage

- Click a checkbox or use a number key to enable/disable the overlay for the corresponding display.
- Press `<Shift>` to easily identify which display corresponds to what number.
- Use the scroll wheel to adjust the opacity of the overlay.
- You can double-click an overlay to close it.
